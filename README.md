# EcoRecycle

EcoRecycle is a Minecraft mod designed for environmental cleanup. It introduces a variety of trash items scattered throughout the world, which players can collect, recycle, and sell to upgrade their machines. The mod features a tiered system where players must complete each tier to unlock the next, ensuring a progressive and engaging gameplay experience.

## Install

1. Download the mod file from the GitHub repository.
2. Place the downloaded file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft with the Forge mod loader.

## Use

1. Collect various types of trash scattered around the world.
2. Recycle the collected trash to earn in-game currency.
3. Use the earned currency to purchase upgraded machines.
4. Progress through the tiered system by completing each tier to unlock new machines and challenges.
